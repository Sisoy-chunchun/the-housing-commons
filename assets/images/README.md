# Photography and illustration placeholders

The initial working website contains NO AI-generated people photography. The homepage currently uses `../graphics/shared-housing.svg`, an editable conceptual architectural drawing, not an actual property or development.

When authentic photography is selected, place licensed or permission-cleared images in this folder, update the image path in the relevant HTML file, and adjust its CSS styling as needed. Keep meaningful alt text. Do not represent illustrative or stock images as verified Nebraska projects.
